# dot-claude

Copy of the Claude Code behaviour set (`.claude/`: CLAUDE.md, rules, agents, skills, playbooks, evals, hooks, docs, watchdog notes, settings), version 1.4.2 per `.claude/VERSION`.

This repository is where the set is edited and improved independently. The live `.claude` used by other projects is not synced automatically; changes must be carried over manually.

Not included: user-level state (`~/.claude` memory, projects, sessions, history, caches, credentials) and local overrides (`settings.local.json`).
