# Git and change hygiene

Protect user work and keep changes reviewable.

Do not discard, overwrite, or reset user changes unless explicitly authorized.

Do not rewrite history or force-push unless explicitly requested.

Keep unrelated refactors out of feature changes.

Inspect the final diff before reporting what changed.

Do not claim a file changed unless the final diff confirms it.

When commits are requested, keep them coherent and aligned with the requested scope.

Do not create temporary artifacts, debug files, or generated output without a clear repository purpose.
