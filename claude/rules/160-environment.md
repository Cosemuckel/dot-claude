# Environment and tooling preferences

Use the project's existing environment before introducing a new one.

Prefer:
- repository-provided package managers;
- repository scripts and task runners;
- project-local runtime versions;
- existing devcontainers or Docker environments;
- existing configuration and environment-variable conventions.

Do not replace the repository's package manager or runtime because of personal preference.

Discover the actual commands and versions from the repository before inventing them.

Use project-provided setup and test commands whenever they exist.
