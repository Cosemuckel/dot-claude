# Code intelligence and repository navigation

Prefer precise symbol and structure navigation when available.

Use an existing language server, IDE index, semantic code tool, or project code-intelligence integration when
it can answer the question more directly than broad text search.

Use targeted `Read`, `Grep`, and `Glob` when they are sufficient.

Do not scan the repository indiscriminately when a symbol, reference, definition, or path-specific query can
establish the answer.

Serena is optional. Use it only when explicitly enabled and when semantic navigation/refactoring materially
improves the task.

Do not add an MCP or plugin merely to replace a capability already provided by the project's native tooling.
