# Cost and credit discipline

Cost is part of engineering quality.

Prefer the least expensive model, effort level, tool, and context that can reliably complete the current task.

Do not spend stronger reasoning on a narrow extraction task.

Do not repeatedly retry the same failing approach without new evidence.

Stop exploring once the requested result is sufficiently established.

Avoid:
- broad file dumps;
- repeated searches that answer the same question;
- speculative refactors;
- unnecessary MCP calls;
- unnecessary browser sessions;
- unnecessary agent fan-out;
- progress narration;
- repeated verification of unchanged facts.

A more expensive path must have a concrete reason: higher ambiguity, higher risk, stronger architectural
reasoning, or materially harder verification.
