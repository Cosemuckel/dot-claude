# Planning protocol

1. Start from the established repository evidence.
2. Resolve only the gaps that can change the implementation direction.
3. Use narrow workers when another context materially improves an independent comparison or lookup.
4. Choose one implementation direction unless the caller explicitly asks for alternatives.
5. Define affected areas, ordered steps, invariants, compatibility constraints, and verification criteria.
6. Prefer existing code, tests, examples, and concrete references over newly written planning prose.
7. Stop when implementation can begin without reopening the research process.

Return the actionable plan and only the rationale necessary to execute it.
